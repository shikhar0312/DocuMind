# DocuMind — Agent Instructions

Before implementing a feature, read these files in order:

1. `Backend/Context/project-overview.md`
2. `Backend/Context/architecture.md`
3. `Backend/Context/ui-context.md`
4. `Backend/Context/code-standards.md`
5. `Backend/Context/ai-workflow-rules.md`
6. `Backend/Context/progress-tracker.md`

Use `Backend/Design/` as the visual source of truth for the five UI reference images.

Implement one scoped, verifiable feature at a time. Follow the documented architecture and standards. Do not invent product behavior or make material architecture/security decisions without clarification.

After meaningful changes, update `Backend/Context/progress-tracker.md`. Mark items `[x]` only after completion and verification. Update the relevant context file whenever architecture, scope, data, authentication, storage, UI conventions, or standards change.
